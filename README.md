## Publish later

1. Copy `index.html` and `style.css` to the root of the `prkpushp.github.io` repository (or another repo with Pages enabled). Leave `REVISION-LOG.md` out of the site if you do not want the notes public.
2. In Settings → Pages, deploy from the branch that holds those two files (usually `main`, folder `/`).
3. Do not add a phone number, personal email, pay, notice period, or current employer name. LinkedIn is the contact link.

`REVISION-LOG.md` records the ten editing passes. It is not part of the page.
