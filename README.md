# Pushp Ranjan Karn — Portfolio

Static personal portfolio for GitHub Pages.

## Publish on GitHub Pages

1. Create a new repository (for example `prkpushp.github.io` or any repo with Pages enabled).
2. Copy `index.html` and `style.css` to the **repository root** (Pages serves `index.html` from root for user/org sites, or from the configured branch/folder for project sites).
3. In the repo **Settings → Pages**, set the source to the branch that holds these files (usually `main` / root).
4. Do not commit phone numbers or personal email; LinkedIn is the public contact link.

No build step. Open `index.html` locally in a browser to preview.
